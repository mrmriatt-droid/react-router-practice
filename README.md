# React Router Practice

A responsive React application built to practice React concepts, routing, state management, and API integration.

## Features

- Product management (Add, Edit, Delete).
- Shopping cart with quantity controls and total calculation.
- Users list with search and pagination.
- User details with interactive map.
- Dashboard with nested routes (Profile & Settings).
- Data persistence using Local Storage.
- Reusable components and custom hooks.
- Responsive design.

## Technologies Used

- React
- JavaScript
- React Router DOM
- Context API
- React Hooks
- Vite
- CSS3
- React Leaflet
- OpenStreetMap
- JSONPlaceholder API
- Local Storage
